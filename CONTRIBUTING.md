# Contributing

Contributions to MOCHA are welcome through GitHub issues and pull requests.

Before submitting a contribution:

- keep changes focused and documented;
- do not commit datasets, credentials, private paths, or proprietary files;
- do not add third-party code or model weights without clear provenance and compatible redistribution terms;
- preserve existing copyright and license notices;
- include tests or reproducibility information when appropriate.

By contributing source code, you agree that your contribution may be distributed under the repository's MIT source-code license.

Model checkpoints and datasets are governed separately by `LICENSE-WEIGHTS.md` and `DATASETS.md`.
